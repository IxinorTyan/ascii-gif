# Suzu ASCII Studio

双击仓库根目录的 `启动新版.bat`（或 `start_studio.bat`），浏览器会自动打开本机工作室。本目录内也有 `启动工作室.bat`。保持启动窗口运行，关闭它或按 Ctrl+C 即停止服务。视频或 GIF 只发送到本机 Python 服务，服务监听 `127.0.0.1`，不会上传网络。旧版启动脚本和源代码仍然保留。

流程：导入媒体 → 拖动时间轴预览 → 调整字符参数 → 选择起止帧和导出帧率 → 导出 HTML。

导出的 HTML 是独立文件，帧中的内容是字符文本和彩色字符 `<span>`，可离线播放。播放器支持暂停、重播、进度、倍速和循环；导出文件也可以用 `?embed=1` 隐藏控件后嵌入网页。

视频解码使用 OpenCV；GIF 使用 Pillow。安装依赖：`python -m pip install opencv-python pillow`。可选安装 `ffmpeg` / `ffprobe` 以读取可变帧率视频的原始时间戳。

## 使用

- 初次使用可点击“试试示例动画”，无需准备文件。
- 拖动时间轴或点击上一帧、下一帧查看效果，调整参数后自动重新渲染。预览字符与导出共用同一渲染器。
- “播放预览”会循环播放所选片段。为了保持时间进度，预览在解码跟不上时会跳过画面；导出会转换计划中的每一帧。
- 起止帧编号从 0 开始，**包含结束帧**。与旧程序不含结束帧的规则不同。
- 默认保留全部源帧。可以减少抽帧密度以减小体积，片段总时长不变。抽帧密度是近似值，不会为低帧率素材插入重复帧。
- 视频时间戳不可用时，界面会明确显示使用平均帧率。GIF 的零时长或缺失时长按 100 ms 处理。
- 支持彩色 / 单色、字符预设、自定义字符、灰度反转、空格、列数、宽高修正、亮度、对比度、字体和字号。
- 输出不含音频。导出后可再次下载或点击“预览导出结果”；本地服务关闭后，已保存的 HTML 仍可独立播放。
- 开启压缩时，播放器需要支持 `DecompressionStream` 的现代浏览器；也可以关闭压缩导出普通 JSON 数据。
- HTML 播放器复用彩色字符节点，只更新变化的字符和颜色；不再每帧重新测量画面。按源帧时长调度，暂停或切换到后台时停止调度，回到页面后继续播放。载入后释放内嵌 JSON 文本，并将颜色数组转为紧凑的数值数组。高列数、彩色和高帧率仍会增加绘制开销。
- 播放器代码内嵌在每个导出文件中；升级后需要重新导出 HTML，旧文件不会自动获得优化。
- 适合网页动画和短片段。单次输入上限 1 GB，导出上限 6000 帧 / 约 120 MB 未压缩字符数据。长片段或彩色模式建议降低列数、抽帧密度，支持中途取消。
- 自定义字符建议使用等宽的普通字符和方块符号；emoji 和组合字符会受字体宽度影响。

## 流畅背景 HTML

HTML 用途默认选择“流畅背景（Canvas，推荐）”，适合把一段视频做成整页背景。导出文件自动循环、无按钮或进度条，按窗口比例铺满（必要时裁边）。背景模式显示的是 Canvas 上的字符效果，不能像文字模式那样选择复制字符；需要真实文字节点时切换为“可复制字符”。

背景导出最多抽取约 30 帧/秒，保留片段总时长。画布最长边限制为 1280 像素，不按屏幕高 DPI 额外放大；字符图块缓存最多 2048 个，整帧位图缓存最多 24 MiB 并复用淘汰的画布。字符形状和颜色分开合成，避免反复绘制不同颜色的字体；保留原始字符颜色。短循环缓存命中后可直接贴图，长片段超出缓存后仍需重绘。后台停止调度，恢复后继续；绘制跟不上时跳帧，不累计过期帧。

优先尝试 80–100 列、24 帧/秒。此模式降低排版与文字绘制开销，但流畅度仍取决于设备、帧大小和片段内容。需要重新导出才能获得新播放器，旧文件不会自动更新。

## 导出 ASCII GIF

右侧新增“导出 ASCII GIF”，支持视频和 GIF 输入，沿用字符效果、片段范围、抽帧密度与循环设置。最长边上限可选 480 / 640 / 960 像素；只缩小，不放大原本的字符画。推荐 480 像素和约 12 帧 / 秒。

字符在导出时绘制成图片并逐帧编码，播放时直接使用图片解码，无需反复创建字符节点。导出过程不保存整个图片序列在内存中，支持进度、取消、下载和页面内动图预览。GIF 可直接用 `<img src="ascii_demo.gif" alt="ASCII 动画">` 嵌入网页。

GIF 不含音频，每帧最多 256 色，因此彩色效果会有量化差异。时长按 GIF 的 10 毫秒精度累计舍入，小于 20 毫秒的帧合并以避免浏览器将极短帧当作长延时；总时长通常仅有毫秒级舍入误差。输出上限为 6000 帧、100 MB；播放控件和压缩数据开关仅影响 HTML。生成 GIF 仍需处理器计算，播放开销和文件体积取决于尺寸及帧数。

## 开发与验证

没有前端构建步骤、Node 运行时依赖或 CDN。启动命令为 `python studio/server.py`；`--no-browser --port 8766` 可指定端口且不自动打开浏览器。

```text
python -m unittest discover -s studio/tests -v
node --test studio/tests/core.test.mjs
```

`server.py` 负责本机上传与帧解码，`web/ascii.mjs` 负责字符转换，`web/renderer.mjs` 同时用于预览与导出，`web/export.mjs` 生成独立动画播放器。字符处理参数及预设改编自 SuzuVisualLab（MIT），授权声明保存在 `LICENSE-SuzuVisualLab`。示例 GIF 为本项目程序生成的原创测试素材，可用 `python studio/make_demo.py` 重新生成。
